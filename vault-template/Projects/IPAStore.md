# IPAStore

Telegram-бот и Mini App: магазин IPA с подпиской, подписью и установкой по воздуху, маркетплейс для инди-разработчиков.

- `health` — адрес проверки работоспособности, например `https://ваш-домен/health`.
- `stats_url` — метрики магазина для дашборда: `https://ваш-домен/jarvis/stats`
  (токен — в переменной окружения из `stats_token_env`, тот же, что `JARVIS_TOKEN` в .env IPAStore).
