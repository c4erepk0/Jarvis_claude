# Протоколы

Свои протоколы: заголовок `## Протокол «Название»` и список команд — Jarvis выполнит их по очереди.
Запуск голосом: «Джарвис, протокол Старт работы». Встроенные протоколы: Утро, Фокус, Итоги дня,
Неделя, Диагностика, Чистый лист, Вечеринка (статус и выкатка всех проектов), Тишина.

## Протокол «Старт работы»
- протокол фокус
- задачи на сегодня
- статус проектов

## Протокол «Перед сном»
- итоги дня
- задачи на завтра
