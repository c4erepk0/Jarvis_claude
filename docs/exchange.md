# Обмен файлами с операторами

Встроенное приложение Atom («Обмен файлами», ⇅, `builtin:exchange`): владелец передаёт операторам файлы и
принимает их обратно. Всё лежит **на своём сервере** — ни облака, ни внешних токенов.

- Код: [`jarvis/fileshare.py`](../jarvis/fileshare.py), окно — [`static/exchange.js`](../jarvis/webapp/static/exchange.js)
- Хранилище: `data/exchange/` (рядом с `data/`, **не** в хранилище Obsidian — бинарники не синхронизируются)
- Права оператора: `files: [{path, name, level}]` в `jarvis/operators.py`
- Тесты: `tests/test_fileshare.py`

## Как это выглядит

1. Владелец открывает каталог (⊞) → **«Обмен файлами»**: создаёт папки, загружает файлы, видит занятое место.
2. У папки — кнопка **«Доступ»**: кому из операторов открыта и можно ли в неё загружать.
3. Оператор открывает «Обмен» в своём каталоге (или вкладку «Обмен» в кабинете): видит только выданные папки,
   скачивает файлы и загружает свои, если уровень позволяет.

## Уровни доступа

| Уровень | Что может оператор |
|---|---|
| `view` — просмотр | открыть папку, смотреть список, скачивать файлы (и из подпапок) |
| `upload` — просмотр и загрузка | то же + загружать файлы в эту папку и её подпапки |

Папка выдаётся как корень: доступно её поддерево, соседние папки — нет. Проверка идёт по пути
(`FileShare.contains`), а не по тому, что прислал браузер.

Отдельного уровня «редактировать» и удаления у оператора нет: он может только класть файлы. Это осознанно —
чужой файл нельзя случайно перезаписать или стереть.

## Что где лежит

```
data/exchange/                 корень обмена (создаётся при первом запуске)
  Договоры/                    папка = папка в приложении
    2026-аренда.pdf
  Фото с объекта/
    IMG_0421.jpg
```

Метаданных нет: список — это содержимое папки, размер и дата — из файловой системы. Поэтому:
- переименовали папку на диске — в приложении она тоже переименовалась;
- выданная папка исчезла — у оператора она просто не показывается.

## Настройки

```ini
# data/exchange живёт в data/, отдельной настройки пути нет
EXCHANGE_MAX_MB=32        # больше этого файл не принимаем (1–200)
EXCHANGE_QUOTA_MB=2000    # общий объём хранилища, МБ
```

Занятое место видно в шапке приложения и в «Команде». При заполнении квоты загрузка отвечает понятной
ошибкой, а не молча падает.

## API

| Метод | Кто | Что делает |
|---|---|---|
| `GET /api/exchange?folder=&q=` | владелец | список папки, занятое место, квота |
| `POST /api/exchange/mkdir` | владелец | создать папку (`name`, `parent`) |
| `POST /api/exchange/upload` | владелец | загрузить файл (форма: `file`, `folder`) |
| `POST /api/exchange/delete` | владелец | удалить файл или пустую папку (`id`) |
| `POST /api/exchange/share` | владелец | выдать/изменить доступ (`op`, `path`, `name`, `level`; `level: ""` — убрать) |
| `GET /api/exchange/raw/{id}` | владелец | скачать файл; `?inline=1` — показать картинку |
| `GET /api/op/exchange` | оператор | выданные папки |
| `GET /api/op/exchange/list?folder=` | оператор | содержимое выданной папки |
| `POST /api/op/exchange/upload` | оператор | загрузить в папку с уровнем `upload` |
| `GET /api/op/exchange/raw/{id}` | оператор | скачать файл из выданной папки |

`id` — относительный путь внутри `data/exchange/` (например `Договоры/2026-аренда.pdf`), в URL — с
кодированием. Ошибки — текстом на русском: «папка вам не открыта» (403), «файл больше 32 МБ» (400).

## Безопасность

- **Пути.** Только нормальные сегменты: без `..`, абсолютных путей, скрытых имён и глубже шести уровней;
  итоговый путь обязан лежать внутри корня (проверка по `resolve()` — симлинки не обманут).
- **Имена.** Чистятся от `/ \ : * ? " < > |` и управляющих символов; дубликат получает ` (2)`.
- **Размер и квота.** Файл — до `EXCHANGE_MAX_MB`, всё хранилище — до `EXCHANGE_QUOTA_MB`.
- **Запись.** Атомарная (временный файл + `os.replace`): оборванная загрузка не оставляет половину файла.
- **Скачивание.** Всегда вложением (`Content-Disposition: attachment`), картинки — `inline` только по
  `?inline=1`; браузер ничего не исполняет с этого адреса.
- **Доступ.** Оператор видит только выданные папки; личные заметки, финансы и чат к обмену не относятся
  и по-прежнему закрыты.

## Ограничения

- **Один сервер.** Файлы не синхронизируются между устройствами: это хранилище Atom, а не облако.
- **Нет версий и корзины.** Удалённый файл исчезает сразу (подтверждение — в интерфейсе, второй клик).
- **Нет докачки и фоновой загрузки.** Большой файл грузится одним запросом; видео лучше класть пачками.
- **Нет публичных ссылок.** Скачать может только владелец или оператор с доступом, после входа.
- **Резервная копия — ваша.** `data/exchange/` стоит включить в бэкап сервера (например, `rsync` в ночной cron).

## Если не работает

| Симптом | Причина |
|---|---|
| «папка вам не открыта» | владелец не выдал её оператору или забрал доступ |
| «здесь можно только смотреть и скачивать» | уровень `view` — загрузка запрещена |
| «не хватает места» | достигнута квота `EXCHANGE_QUOTA_MB` — удалите лишнее или поднимите квоту |
| «файл больше 32 МБ» | поднимите `EXCHANGE_MAX_MB` (до 200) |
| «папка не пуста» | удалять можно только пустые папки: сначала файлы внутри |
