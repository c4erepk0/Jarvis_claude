# Jarvis на iPhone

Два способа — выберите один:

- **А. Без сервера** (ниже, разделы 1–4): Jarvis открывается с GitHub Pages и всё делает прямо в Safari.
- **Б. В Linux-терминале** (раздел «Вариант Б» в конце): тот же Python-сервер, что на компьютере,
  открывается в Safari по https-ссылке туннеля.
- **В. На своём VPS** (150–500 ₽ в месяц) — постоянная ссылка, работает при выключенном телефоне:
  [docs/hosting.md](hosting.md).

## Вариант А — без компьютера и без сервера

Jarvis целиком работает в Safari на телефоне: ядро (задачи, финансы, память, протоколы, мозг Claude) —
это JavaScript в самом приложении. Ставить IPA не нужно: приложение открывается с GitHub Pages и
добавляется иконкой на экран «Домой».

```
 iPhone ─ Jarvis (Safari, иконка на экране «Домой») ─┐
                                                     ├─ GitHub: приватный репозиторий jarvis-vault (память)
 iPhone ─ Obsidian + плагин Obsidian Git ────────────┘        │
                                                              └─ GitHub Actions раз в 15 мин → Telegram
 Claude API ← Jarvis (прямо с телефона, ключ хранится только на нём)
```

Всё бесплатно, кроме запросов к Claude API (без ключа Jarvis работает на командах).

### 1. GitHub (в Safari или приложении GitHub)

1. **Репозиторий памяти.** New repository → имя `jarvis-vault` → **Private** → поставьте галочку
   «Add a README file» → Create.
2. **Сайт приложения.** Слейте PR с Jarvis в `main`. Затем в репозитории `Jarvis_claude`:
   Settings → Pages → Source: **GitHub Actions**. Через минуту приложение будет по адресу
   `https://c4erepk0.github.io/Jarvis_claude/`.
   На бесплатном тарифе GitHub Pages работает только для публичных репозиториев: сделайте
   `Jarvis_claude` публичным (Settings → General → Change visibility). В коде нет ключей и личных
   данных — они живут только на телефоне и в приватном `jarvis-vault`.
3. **Токен.** Settings (профиля) → Developer settings → Fine-grained tokens → Generate:
   - Repository access: `jarvis-vault`, `IPAStore`, `Jarvis_claude`;
   - Permissions: **Contents** — Read and write, **Issues** — Read and write,
     **Actions** — Read and write (деплой и статус CI), Metadata — Read;
   - срок — до года. Скопируйте токен.

### 2. Jarvis на экран «Домой»

> Сначала добавьте на экран «Домой», потом настраивайте: у приложения с экрана «Домой» на iOS своё
> хранилище, отдельное от Safari.

1. Откройте адрес из шага 1.2 в **Safari** → «Поделиться» → **«На экран „Домой“»**.
2. Запустите Jarvis с иконки. Откроется настройка:
   - ключ Claude API (console.anthropic.com → API Keys) — для свободной речи, поиска и фото чеков;
   - токен GitHub из шага 1.3 и репозиторий `c4erepk0/jarvis-vault`;
   - город (кнопка «⌖ ЗДЕСЬ» возьмёт координаты телефона).
3. «Сохранить» → «Создать» — в репозиторий ляжет стартовая структура памяти.
4. Голос: Настройки iPhone → Универсальный доступ → Устный контент → Голоса → Русский →
   скачайте **«Юрий (улучшенный)»** — мужской голос для Jarvis. Выбрать его можно в ⚙ Jarvis.

Микрофон: кнопка 🎤 или касание реактора. Переключатель «Джарвис — постоянное прослушивание»
слушает слово-активатор, пока приложение открыто и экран включён. Если iOS не даёт распознавание
речи, используйте микрофон на клавиатуре — команды те же.

### 3. Obsidian на iPhone

1. Установите **Obsidian** из App Store → создайте хранилище `Jarvis`, место — **«На iPhone»**
   (не iCloud: две синхронизации одной папки мешают друг другу).
2. Настройки → Сторонние плагины → включить → Обзор → **Git** (автор Vinzent03) → Установить → Включить.
3. Настройки плагина Git → Authentication: имя пользователя GitHub и токен из шага 1.3.
4. Командная палитра (свайп вниз) → **«Git: Clone an existing remote repo»** →
   `https://github.com/c4erepk0/jarvis-vault.git` → папка — корень хранилища → перезапустите Obsidian.
5. В настройках плагина: **Auto commit-and-sync interval = 1**, **Auto pull interval = 1**,
   **Pull on startup** — вкл.

Теперь задача, добавленная голосом в Jarvis, через минуту появится в Obsidian, а заметка из Obsidian —
в Jarvis (он проверяет GitHub каждые 15 секунд и сразу при открытии).

### 4. Оповещения, когда Jarvis закрыт (по желанию)

Пока приложение открыто, напоминания звучат голосом. Чтобы они приходили и при закрытом приложении,
Jarvis раз в 15 минут запускается в GitHub Actions и пишет в Telegram:

1. В Telegram: @BotFather → `/newbot` → токен бота; свой ID — у @userinfobot. Напишите своему боту `/start`.
2. В репозитории `Jarvis_claude` → Settings → Secrets and variables → Actions:
   - Variables: `VAULT_REPO` = `c4erepk0/jarvis-vault` (и при желании `BRIEFING_TIME`, `WEATHER_CITY`);
   - Secrets: `VAULT_TOKEN` (токен из шага 1.3), `TELEGRAM_BOT_TOKEN`, `TELEGRAM_OWNER_ID`.
3. Actions → «Jarvis — оповещения» → Run workflow — проверка.

Что приходит: наступившие напоминания, утренний брифинг (в `BRIEFING_TIME`), упавшие сборки CI проектов.
Для публичного репозитория минуты Actions бесплатны; для приватного проход раз в 15 минут — около
1500 минут в месяц (частоту можно уменьшить в `.github/workflows/jarvis-cron.yml`).

## Метрики IPAStore на карточке проекта

Когда IPAStore заработает: в его `.env` — `JARVIS_TOKEN`, в заметке `Projects/IPAStore.md` —
`health: https://ваш-домен/health` и `stats_url: https://ваш-домен/jarvis/stats`, а в ⚙ Jarvis —
строка `IPAStore=<тот же токен>` в «Токены метрик проектов».

## Что важно знать

- **Ключи** хранятся только в приложении на этом iPhone. ⚙ → «Сбросить» удаляет их.
- **Синхронизация** почти в реальном времени: Jarvis видит изменения GitHub за ~15 секунд, Obsidian
  синхронизируется с GitHub раз в минуту. Одновременные правки одной заметки сливаются: Jarvis
  перечитывает файл и применяет своё изменение заново.
- **Голос** — системный голос iPhone. Нейроголос и «металлический» эффект ИИ доступны в серверной
  версии и появятся в нативном приложении.
- **Siri и работа в фоне** — ограничения веб-приложений iOS. Это следующий шаг: нативное приложение
  (IPA), которое можно будет ставить через IPAStore.
- Без интернета работают команды и уже загруженная память; изменения сохранятся, как только появится сеть.

## Вариант Б — Jarvis в Linux-терминале (на iPhone, VPS или в облаке)

Safari не видит `localhost` терминала, поэтому Jarvis открывается по https-ссылке туннеля.

1. Создайте приватный репозиторий памяти `jarvis-vault` и токен — как в разделе 1 варианта А.
2. В терминале, в папке `Jarvis_claude`, откройте `.env` (`nano .env`) и задайте:
   ```
   VAULT_GIT=c4erepk0/jarvis-vault
   GITHUB_TOKEN=github_pat_…
   ANTHROPIC_API_KEY=sk-ant-…        # по желанию — свободная речь
   ```
   Если в папке `vault/` уже есть заметки, Jarvis отложит их в `vault.local-<дата>` и скачает хранилище
   из репозитория (а если репозиторий пуст — отправит туда свои).
3. Запуск: `bash start.sh --tunnel`. Jarvis напечатает рамку со ссылкой `https://….trycloudflare.com`
   и кодом входа (он сохранится в `.env`). Откройте ссылку в Safari, введите код →
   «Поделиться» → «На экран „Домой“».
4. Obsidian на iPhone подключите к тому же репозиторию (раздел 3 варианта А): Jarvis забирает правки
   с телефона и отправляет свои каждые 20 секунд, одновременные правки одной заметки сохраняются обе.

Важно: iOS приостанавливает приложения в фоне. Если терминал работает внутри приложения на самом
iPhone, Jarvis «засыпает», когда вы переключаетесь в Safari, и ссылка перестаёт открываться — для
телефона без сервера подходит вариант А. На VPS или в облачном терминале Jarvis работает постоянно.
Ссылка Cloudflare меняется при каждом запуске; постоянный адрес — свой домен в Cloudflare Tunnel или Tailscale.

Если ссылка показывает **«no tunnel»** или Safari пишет «не удаётся подключиться к серверу»:
- набирайте не `localhost`, а только https-ссылку из рамки;
- вернитесь в терминал: Jarvis каждые 30 секунд проверяет ссылку снаружи и, если туннель оборвался,
  поднимает новый и печатает рамку «Ссылка сменилась» (новый адрес — ещё и в `data/tunnel_url.txt`
  и в Telegram, если он настроен);
- если не поднялся ни один туннель, в строке «❌ … не поднялся: …» видна причина (полный вывод —
  `data/tools/tunnel.log`). Выбрать способ вручную: `bash start.sh --tunnel pinggy`.
