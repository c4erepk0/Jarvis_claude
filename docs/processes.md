# Процессы Atom: инвентаризация, дубли и новая структура

Документ отвечает на три вопроса: **что в Atom есть**, **где это начать** и **что было продублировано**.
Составлен по коду `main` (ноябрь 2026), после реструктуризации интерфейса. Держите его рядом с
[CLAUDE.md](../CLAUDE.md): там карта модулей, здесь — карта дел и точек входа.

## 1. Как устроен Atom

Три слоя, один источник правды:

```
Экран (webapp/index.html + static/*.js)
  ↓ /api/… и /ws
Сервер (jarvis/web.py → jarvis/core.py)
  ↓
Файлы: vault/*.md (память Obsidian) + data/* (служебное)
```

- **Экран** — ES-модули без сборки. Окна открывает `static/windows.js`, каталог приложений — `static/apps-catalog.js`.
- **Сервер** — действия `act_*` в `core.py`, маршруты в `web.py`. Одно действие = один `act_*` + маршрут.
- **Память** — только файлы. Задачи, встречи, проекты, финансы и заметки — markdown, который правит человек
  в Obsidian. Базы и ORM нет.

Два режима: сервер (Python) и «только iPhone» (порт ядра в `static/core/`). Логика и формат заметок в них
обязаны совпадать; интерфейс — один.

### Где что начинается на экране

| Экран | Что это | Как открыть |
|---|---|---|
| Главная | задачи, встречи, протоколы, память, ядро с командой, журнал, проекты | вкладка «Главная» / старт |
| Задачи | левая колонка целиком | вкладка «Задачи» (телефон) |
| Проекты | правая колонка | вкладка «Проекты» (телефон) |
| Приложения | все инструменты, сгруппированные по делу | вкладка «Приложения» / кнопка ⊞ (компьютер) |
| Окна | хранилище, финансы, карта, глобус, команда, обмен, настройки, чужое приложение | плитка в каталоге или контекстная кнопка |

Контекстные кнопки остались только там, где продолжают дело: «⤢» у встреч ведёт в «Команду» на вкладку
встреч, «▤» у памяти — в «Хранилище», «◈ Граф памяти» — в голограмму. Это не второй способ открыть то же
окно, а переход с уже выбранным контекстом.

## 3. Что было продублировано (и что стало)

| Дубль | Было | Стало |
|---|---|---|
| `esc()` — экранирование HTML | **6 копий** в `app.js`, `markdown.js`, `fin-charts.js`, `map.js`, `gaze-calibration.js`, `gesture-tutorial.js`; две копии не закрывали `'` | одна в `static/util.js`; остальные импортируют (или реэкспортируют для совместимости) |
| Открытие окна | **9 копий** «`if (!x) import; new X; await x.show()`» + свой `let` на каждое | `static/windows.js`: регистрация, ленивая загрузка, одно окно на экране |
| Esc | цепочка `if (av) … else if (gw) … else if (mw) …` на 9 окон | `wins.dismiss()`: верхнее открытое, с уважением к «не закрывать» |
| «Сегодня» | 4 ручных сборки `ГГГГ-ММ-ДД` | `todayISO()` в `util.js` (понимает и `S.now` сервера) |
| Дата для человека | 2 разные `fmtDate` | `fmtDay()` в `util.js` |
| `dist()` | 2 копии в `gestures.js` и `gaze.js` | `geom.js` |
| `prefers-reduced-motion` | 2 копии | `reduced()` из `motion.js` |
| Точки входа в «Команду» и «Настройки» | кнопки в шапке **и** плитки каталога | шапка: только статус, часы и ⊞; всё остальное — каталог |
| Раскладка главной | 2 объявления `.layout` (4 колонки, затем 3) | одно на 3 колонки, `max-width: 1600px` |
| Мёртвый CSS | `.bg-grid`, `.bg-scan`, `.settings-btn`, `.team-btn`, `.col-right2` | удалено |
| Заголовки панелей | КАПС + красный + свечение (вопреки CLAUDE.md) | обычный регистр, светлый текст, тонкая красная черта |

Проверка дублей: `tests/js/util.test.mjs`, `tests/js/windows.test.mjs`, `tests/js/apps-catalog.test.mjs`.

## 4. Новая структура интерфейса

### Навигация

- **Главная** — три колонки: дела слева (задачи, встречи, протоколы, память), ядро в центре, проекты справа.
- **Приложения** — единственный каталог инструментов. Группы отвечают на «где это?»:
  - **Дела** — Хранилище, Финансы, Карта;
  - **Люди** — Команда, Обмен файлами;
  - **Анализ** — Глобус, Граф памяти;
  - **Система** — Настройки и диагностика.
- **Шапка** — состояние (BRAIN / SYNC / VOICE / TG), часы, погода. Кнопок-дублей нет.
- **Телефон** — нижняя навигация: Главная · Задачи · Проекты · Приложения. Кнопка ⊞ в шапке скрыта,
  чтобы не было двух входов в одно и то же.
- **Компьютер** — нижней навигации нет, поэтому ⊞ остаётся в шапке.

### Окна

Все окна — один `WindowManager` (`static/windows.js`):

```js
wins.register("finance", { load: async () => new FinanceWindow(...) });
await wins.open("finance", tab);   // закроет предыдущее, покажет это
wins.dismiss();                    // Esc: верхнее открытое
```

Правила:

1. Одно окно на экране. Новое закрывает предыдущее.
2. Окно, которое отказалось закрываться (несохранённая правка в «Хранилище»), отменяет переход.
3. `load()` вызывается один раз — модуль и DOM не пересоздаются.
4. Esc обрабатывается в одном месте, а не в девяти.

## 5. Дизайн: правила, по которым теперь собран интерфейс

Стиль описан в [CLAUDE.md](../CLAUDE.md): тёплый графит, красный акцент, Manrope, спокойно и без HUD-клише.
Код приведён к этому описанию.

| Правило | Как в коде |
|---|---|
| Акцент — только действие и состояние | красная черта у заголовка, активная вкладка, опасное; фон — графит |
| Без сканлайнов, сетки и уголков-прицелов | удалены `.bg-scan`, `.bg-grid`, `::before/::after` у панелей |
| Заголовки обычным регистром | `.panel-h`: 15 px, 650, `var(--bright)`, без `text-shadow` |
| Одна форма у управления | панели 12 px, кнопки/поля/сегменты 8 px, бейджи 999 px |
| Фокус виден, но не светится | кольцо `--focus`, без красного ореола |
| Меньше красной заливки | фон и шапка — нейтральный графит; красный остался акцентом |
| Поиск и группировка | каталог сгруппирован по делу, поиск по названию и описанию |

## 7. Проверки

- `node --test tests/js/windows.test.mjs` — 5/5.
- `node --test tests/js/util.test.mjs` — 3/3.
- `node --test tests/js/apps-catalog.test.mjs` — 6/6.
- `node --test tests/js/assets-version.test.mjs` — версия `?v=` и `V` совпадают (33).
- Все `.js` разобраны Acorn как ES-модули без ошибок.
- Полный `pytest` в iOS-песочнице не гоняем: процесс приложения не выдерживает нагрузку (см. AGENTS.md).
  Python в этой правке не менялся.

В этом окружении Node без полного ICU, поэтому три старых теста форматирования денег/чисел
(`fin-charts`, `motion`, `files`) падают на `450,5` против `450.5`. Это не регрессия: в CI с полным ICU
они проходят.
