# Голос: какой синтез выбрать

Atom умеет шесть синтезаторов. Голос выбирается в `TTS_ENGINE`, остальное — ключи и манера.

| Движок | Русский | Ключ и оплата | Манера | Задержка |
|---|---|---|---|---|
| `yandex` — Yandex SpeechKit | **отличный**, родной | ключ Яндекс Облака, рубли | эмоция `good` / `neutral`, скорость | ~0,5 с |
| `openai` — gpt-4o-mini-tts и совместимые | хороший | `TTS_KEY` (OpenAI или прокси) | **инструкция текстом** | ~1 с |
| `eleven` — ElevenLabs multilingual v2 | очень живой | `TTS_KEY` (сервис закрыт для РФ — через агрегатор) | style 0…1 | ~1–2 с |
| `edge` — нейроголоса Microsoft | хороший, ровный | бесплатно, без ключа | rate / pitch | ~0,7 с |
| `piper` — локально | зависит от модели | бесплатно, офлайн | — | ~0,3 с |
| `browser` — телефон | голос системы | бесплатно | — | мгновенно |

## Что советую

**Для русского и оплаты в рублях — `yandex`.** Это родной синтез с правильными ударениями в датах, суммах
и названиях; сервис доступен без VPN, счёт в рублях, у голосов есть эмоция. На слух он «ровнее» edge:
меньше рубленых пауз, естественнее интонация вопроса.

**Для максимальной выразительности — `openai`.** Модель `gpt-4o-mini-tts` понимает инструкцию о манере:
`TTS_STYLE=говори спокойно, тепло и не спеши; в конце фразы — мягкое понижение` — и правда так читает.
Из России нужен прокси или агрегатор: адрес задаётся в `TTS_URL`, ключ — в `TTS_KEY`.

**`eleven` — самый живой голос**, но сервис официально закрыт для России: по
[разбору на Хабре](https://habr.com/ru/companies/bothubchat/articles/1090610/) оплатить напрямую нельзя,
доступен только через агрегаторы (и у v3 лимит 5 000 знаков на запрос). Атом поддерживает его, если у вас
есть доступ: `TTS_VOICE` — id голоса из библиотеки.

**`edge` оставьте резервом.** Без ключей, работает сразу, но интонация беднее. Если платный синтез не
настроен или упал, Atom просто не отдаст звук — дашборд озвучит ответ голосом телефона.

## Настройка

### Yandex SpeechKit (рекомендую)

1. В [Яндекс Облаке](https://yandex.cloud/ru/docs/speechkit/) включите SpeechKit и создайте API-ключ
   сервисного аккаунта с ролью `ai.speechkit-tts.user`.
2. Каталог (`folder id`) — из консоли облака.
3. В `.env`:

```ini
TTS_ENGINE=yandex
TTS_VOICE=filipp          # filipp, alena, jane, zahar, omazh, ermil, masha, dasha, alexander, kirill
TTS_STYLE=good            # good — теплее, neutral — ровнее
TTS_RATE=-4%              # станет speed ≈ 0.96
YANDEX_API_KEY=…
YANDEX_FOLDER_ID=…
```

### OpenAI или прокси

```ini
TTS_ENGINE=openai
TTS_MODEL=gpt-4o-mini-tts
TTS_VOICE=onyx            # alloy, echo, fable, onyx, nova, shimmer
TTS_STYLE=говори спокойно и тепло, как личный помощник; не спеши
TTS_KEY=sk-…
TTS_URL=                  # пусто — api.openai.com/v1; иначе адрес прокси/агрегатора
```

### ElevenLabs

```ini
TTS_ENGINE=eleven
TTS_VOICE=21m00Tcm4TlvDq8ikWAM   # id голоса из библиотеки
TTS_MODEL=eleven_multilingual_v2
TTS_STYLE=0.2                    # 0 — ровно, 1 — эмоционально
ELEVENLABS_API_KEY=…
```

## Как это устроено

- Текст перед синтезом чистится: без markdown, ссылок, эмодзи и таблиц; «₽» читается «рублей», «%» — «процентов».
- Длина ограничена ~900 символами на запрос: длинный ответ режется по последней точке.
- Ответ кэшируется в `data/tts/` по движку, голосу, манере и тексту — повторные фразы не тратят деньги.
- Любая ошибка синтеза не ломает ответ: Atom пишет предупреждение в журнал и отдаёт текст, дашборд озвучит сам.
- «Металлический» эффект и эхо добавляет Web Audio в дашборде — сервер синтезирует чистый голос.
- Сравнение делалось по документации провайдеров и обзорам: [ SpeechKit](https://yandex.cloud/ru/docs/speechkit/),
  [разбор TTS для русского](https://avatarbox.ru/blog/vybor-tts-dvigka-dlya-russkogo-yazyka-v-2026-testy-elevenlabs-openai-yandex-speechkit),
  [ElevenLabs и РФ](https://habr.com/ru/companies/bothubchat/articles/1090610/). Цены и доступность проверяйте у провайдера.

## Если не работает

| Симптом | Причина |
|---|---|
| ответ без звука, в журнале «не задан ключ» | нет `TTS_KEY` / ключа провайдера |
| «Yandex SpeechKit: не задан YANDEX_FOLDER_ID» | у SpeechKit обязателен каталог |
| «HTTP 401» | ключ не подходит или не та роль у сервисного аккаунта |
| «HTTP 429» | лимит запросов/квота — подождите или поднимите тариф |
| голос читает по-английски русский текст | для `edge` выбран английский голос: Atom подменит на `ru-RU-DmitryNeural` |
