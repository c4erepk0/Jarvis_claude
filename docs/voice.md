# Голос: бесплатные голоса без ключей

Atom говорит только бесплатными синтезаторами — без API-ключей, подписок и оплаты. Выбирается в
**⚙ Настройки → Голос**: там два выпадающих списка и скорость.

| Откуда голос | Что это | Интернет | Качество |
|---|---|---|---|
| **Нейроголос Microsoft** (`edge`, по умолчанию) | нейросетевые голоса Edge/Read Aloud | нужен | естественные паузы, живая интонация |
| **Голос телефона** (`browser`) | `speechSynthesis` — системный голос iOS/Android | нет | зависит от голосов в системе |
| **Piper** (`piper`) | локальная модель `.onnx` | нет | зависит от модели |

## Как выбрать

1. ⚙ → **Голос**.
2. «Откуда голос» — `Нейроголос Microsoft`.
3. «Голос» — **Дмитрий** (мужской, спокойный) или **Светлана** (женский, мягкий).
4. «Скорость речи» — «Обычная». Если кажется быстро — «Чуть медленнее».
5. Сохранить и перезапустить Atom (значения из настроек вступают в силу после перезапуска).

В `.env` то же самое:

```ini
TTS_ENGINE=edge
TTS_VOICE=ru-RU-DmitryNeural     # или ru-RU-SvetlanaNeural
TTS_RATE=+0%
TTS_PITCH=+0Hz
```

Доступные голоса edge проверены запросом `edge_tts.list_voices()` — на сервисе сейчас ровно два русских:
`ru-RU-DmitryNeural` и `ru-RU-SvetlanaNeural`. Поэтому список закрытый: нельзя выбрать голос, которого нет.

## Почему раньше звучало роботом и «ломано»

Три причины, все исправлены:

1. **Скорость и высота были сдвинуты** (`-4%` и `-8Hz`): замедленная и пониженная речь слышится как
   синтезатор из девяностых. Теперь по умолчанию `+0%` и `+0Hz`.
2. **«Металлический» эффект был включён всегда** — короткая гребёнчатая задержка (эхо) и реверберация
   Web Audio. Это киношный приём, но он делает голос дребезжащим. Теперь эффект **выключен**, а включить
   его можно галочкой **«Эффект голоса»** в нижней панели.
3. **Длинный ответ обрезался на полуслове** (по лимиту 900 символов) — звук заканчивался посреди фразы.
   Теперь текст режется по концу предложения, а если предложения не нашлось — по последнему пробелу.

Голос телефона тоже стал нейтральным: `rate=1.0`, `pitch=1.0` (было `0.97`/`0.8`, то есть медленно и низко).

## Где это в коде

- `jarvis/voice.py` — движки, `VOICES`, чистка текста, кэш `data/tts/`.
- `jarvis/settings.py` — `CHOICES`: какие настройки показывать списком, какие полем ввода.
- `jarvis/webapp/static/voice.js` — Web Audio, «эффект голоса», запасной голос телефона.
- Тесты — `tests/test_voice.py`.

## Необязательно: Piper

Без интернета и без Microsoft. Нужна модель `.onnx` (голос) и бинарник `piper`:

```ini
TTS_ENGINE=piper
PIPER_BIN=piper
PIPER_MODEL=/opt/voices/ru_RU-irina-medium.onnx
```

Голоса для Piper лежат в проекте [rhasspy/piper](https://github.com/rhasspy/piper) и на Hugging Face;
качество у них ниже нейроголосов Microsoft, зато всё локально.

## Если не работает

| Симптом | Причина |
|---|---|
| ответ без звука | нет интернета для `edge`; Atom пишет предупреждение в журнал и отдаёт текст |
| звучит медленно и низко | в `.env` остались старые `TTS_RATE=-4%`, `TTS_PITCH=-8Hz` — поставьте `+0%` и `+0Hz` |
| звучит «металлически» | включена галочка «Эффект голоса» — выключите |
| голос женский вместо мужского | выберите «Дмитрий» в настройках или `TTS_VOICE=ru-RU-DmitryNeural` |
| голос читает по-английски | выбран английский голос: для русского текста Atom подменит его на `ru-RU-DmitryNeural` |
